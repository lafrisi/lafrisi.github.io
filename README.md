# Avicenna Alfarisi — Portfolio Site

A continuous engineering portfolio featuring Auto-Thaw, Rolling-Drum Peel Test, and Glue Timelapse. The public site is served from the `main` branch at `https://lafrisi.github.io/`.

## Publishing workflow

The ChatGPT Site is the visual workshop. Review and approve changes there first. Then copy the approved built files from its `dist/` directory into this repository's root, commit, and push to `main`. GitHub Pages publishes the updated root files at the same address. The two sites are intentionally separate; edits to one do not automatically sync to the other.

The peel-test assembly is an illustrative web reconstruction pending further component photographs and CAD dimensions. Font and Three.js licenses are retained under `assets/` and `vendor/`.
